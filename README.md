# TikTok Shop 月度利润核算

用于每月自动核算 TikTok Shop US 店铺真实经营利润。

每个月只需要准备并导出 **4 个文件**：

1.  **美西 OMS**
2.  **美东 OMS**
3.  **当月广告数据**
4.  **TikTok 后台 - 收益数据分析**

> **重要：美东 OMS、美西 OMS 的导出日期范围一定要选得足够长。**
>
> 不要只选择当月 1 日～月末。因为当月结算的 TikTok
> 订单，可能在更早的日期已经下单/创建。
>
> 建议 OMS
> 导出时把日期范围适当向前拉长，确保**当月所有实际出库订单都能够完整导出**。
>
> 后续我会根据 TikTok Order ID /
> 平台单号进行配对，而不是简单按照日期筛选 OMS。

# 五、每月利润核算逻辑

最终利润统一按照以下逻辑计算：

``` text
最终利润
=
TikTok净收益
- 当月广告费
- 海外仓实际出库费用
- 实际出库产品+头程成本
```

其中：

``` text
TikTok净收益
=
TikTok净商品销售额
- TikTok Order Cost
+ 当月 Adjustment
```

> `成本待确认`

# 七、TikTok平台折扣处理

必须区分：

### TikTok平台折扣

例如：

``` text
SKU Platform Discount
TikTok Shop Product Discount
```

这种平台承担的折扣：

> **不能作为商家成本再次扣除。**

例如：

商品原价：

``` text
$25.99
```

商家折扣：

``` text
-$2.00
```

TikTok平台折扣：

``` text
-$12.00
```

客户实际支付：

``` text
$11.99
```

但结算收入可能仍按照：

``` text
$23.99
```

进入商家结算。

因此：

> **不能因为客户只支付 \$11.99，就把 \$12 平台折扣再次从利润里扣除。**

------------------------------------------------------------------------

# 八、退款订单处理

不能简单按照：

``` text
Order Income = $0
```

判断为样品。

可能是：

-   客户退款
-   退款管理费
-   已经实际出库
-   物流索赔
-   索赔成功后产生 Adjustment

例如：

``` text
客户退款
↓
订单收入变成 $0
↓
商品已经实际出库
↓
产生物流/退款相关费用
↓
物流索赔
↓
索赔成功
↓
TikTok Adjustment +$16.99
```

这种订单：

-   **不是样品**
-   产品+头程成本必须计算
-   仓库出库费必须计算
-   TikTok产生的相关费用正常计算
-   Adjustment索赔金额必须计入

------------------------------------------------------------------------

# 九、样品订单

样品必须单独统计。

优先依据 TikTok 字段：

``` text
Sample order type = free sample from seller
```

样品订单：

-   如果实际出库 → 必须计算产品+头程
-   如果仓库产生出库费 → 必须计算仓库费用
-   客户没有付款不代表没有成本

最终会单独输出：

``` text
样品订单数量
样品产品数量
样品产品+头程成本
样品仓库费用
样品订单号
```

------------------------------------------------------------------------

# 十、发货前取消不发货

建立单独分类：

> **发货前取消不发货**

判断原则：

``` text
TikTok订单取消
+
海外仓没有出库记录
+
确认没有实际发货
```

这种订单：

``` text
产品+头程成本 = $0
仓库出库费 = $0
```

因为产品根本没有发出去。

需要单独输出：

-   Order ID
-   SKU
-   数量
-   Order Income
-   Order Cost
-   Order Status
-   原本产品+头程成本
-   实际产品+头程成本
-   实际仓库费用
-   处理结果

# 十一、Order ID 配对规则

核心配对：

``` text
TikTok Order ID
        ↓
海外仓平台单号 / platform No.
```

不要单纯按照：

-   日期
-   SKU
-   金额

进行配对。

优先使用：

> **Order ID 精确匹配**

------------------------------------------------------------------------

# 十二、同一个订单出现多条记录

TikTok 一个 Order ID 可能出现多条结算记录，例如：

-   原始订单
-   退款
-   退款管理费
-   物流费用
-   调整
-   索赔
-   后续结算

所以：

### 财务金额

按照 TikTok 原始结算明细真实汇总。

### 产品成本

不能每一条结算记录都重复扣一次。

应该按照：

``` text
Order ID + SKU
```

确认实际物理出货数量后计算。

------------------------------------------------------------------------

# 十三、海外仓费用

美东 OMS + 美西 OMS 合并。

重点使用：

``` text
平台单号(platform No.)
库内操作费
物流费
出库费用小计
```

同一个 Order ID 如果有多条仓库费用记录：

> 按实际仓库明细合计。

不能因为订单出现多行就重复计算产品成本。

------------------------------------------------------------------------

# 十四、每月必须做的检查

每次计算完成后必须检查：

### 1. TikTok收入校验

``` text
净商品销售额
- Order Cost
+ Adjustment
=
TikTok净收益
```

必须尽可能与后台收益数据分析一致。

------------------------------------------------------------------------

### 2. TikTok ↔ OMS配对

找出：

``` text
TikTok有订单
但OMS没有出库记录
```

这些订单需要分类：

-   发货前取消
-   未发货
-   OMS导出范围不足
-   OMS漏单
-   状态异常
-   其他

------------------------------------------------------------------------

### 3. OMS ↔ TikTok反向检查

找出：

``` text
OMS有出库
但TikTok没有匹配订单
```

需要人工核查。

------------------------------------------------------------------------

### 4. 样品检查

不能用：

``` text
收入 = $0
```

直接判断样品。

必须结合：

``` text
Sample order type
订单状态
OMS出库记录
退款/Adjustment
```

综合判断。

------------------------------------------------------------------------

### 5. Adjustment检查

所有当月 Adjustment 都要单独列出来。

尤其关注：

-   物流索赔
-   退款补偿
-   平台补偿
-   其他赔付

防止漏记，也防止重复记账。

------------------------------------------------------------------------
